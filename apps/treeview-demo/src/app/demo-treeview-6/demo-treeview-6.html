Demo 6 · Lazy children

Each region is a CollapseNode backed by a single lazyBlock placeholder. Collapsed by default. Expand one — the block is now visible, so ensureLoaded() fires; you'll see skeleton rows pulse for {{ '1.2s' }} (simulated latency), then real rows replace them. Scroll position is stable across the load because the placeholder sized itself from totalChildrenCount up front.
