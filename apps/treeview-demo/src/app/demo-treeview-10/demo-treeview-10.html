Demo 10 · Drag-and-drop · all positions + animations

Every row and folder header is wired to cdkDrag. The TreeDragService hit-tests the cursor against the row / header under the pointer and feeds the result to the shared DropHint overlay. On release, the host calls moveRow, moveRowAsChild, or moveCollapse from source-mutation.ts — each splices the underlying data array and the tree node in lockstep, then emits (nodeDropped).

Try every drop case below — the right panel logs each one with the operation kind (row→row, row→folder, folder→folder) and the data array updates in place.

row → row · same lane

Drag a task above or below another task in the same lane. Splices via moveRow.

row → row · cross lane

Drag a task into another lane and drop it next to a sibling task. Source array of the donor lane shrinks, recipient lane grows.

row → folder · drop on header

Drag a task and release on a lane header — task becomes that lane's last child (moveRowAsChild).

folder → folder · reorder lanes

Grab a lane's header and drop it before or after another lane. The synthetic root's rootMeta exposes the lanes array so moveCollapse can splice it.

auto-scroll · drag near edge

Drag a task toward the top or bottom of the viewport. The scroller pans automatically once you enter the 48px hot-zone, speeding up the closer you get to the edge.

shape mismatch · rejected

Dropping a task on the Sprint board header is rejected (root contains lanes, not tasks) — preview animates back. The Sprint board header itself isn't draggable (no parent to move it into).

escape mid-drag · cancelled

Press Esc while dragging — the drop is skipped and the preview snaps back to its origin.
