Demo 12 · Nested cross-tree DnD · workspace → project → task

Three-tier homogeneous structure on each side: Workspace[] at the root, each workspace owns Project[], each project owns Task[]. Every level is draggable, and every level can be a drop target. Both trees share the same accessor shape, so any node can cross between Team A and Team B in a single drag.

task → task

Sibling reorder inside a project, or move a task between projects (within or across trees).

task → project · over

Drop a task on a project header — task lands as that project's last child. Works across trees.

project → project

Reorder projects inside a workspace, or move a project to a different workspace via before/after.

project → workspace · over

Drop a project on a workspace header — becomes that workspace's last project. Cross-tree works too.

workspace → workspace

Reorder workspaces at the top level — the synthetic root's rootMeta exposes the workspaces array for splicing.
